# Contributing to VolViewer

Thank you for helping improve VolViewer. The project is currently developed in a private repository, so issue and pull-request access is limited to invited collaborators.

## Issues

Use an issue to report a reproducible problem, propose a feature, or ask a focused question about the project.

Before opening an issue:

- Search existing issues for duplicates.
- Use a clear, specific title.
- Include the operating system, Python version, Volatility version, and steps to reproduce when relevant.
- Do not attach memory captures or other sensitive forensic evidence. Describe the issue with sanitized details or a minimal safe example.
- Remove passwords, tokens, personal data, and other sensitive information from logs and screenshots.

## Pull requests

1. Create a focused branch from `main`.
2. Keep changes small and explain the problem they solve.
3. Update the README or other documentation when behavior or setup changes.
4. Run the relevant checks before opening the pull request.
5. Include a concise summary of the change and testing performed.
6. Do not commit memory captures, generated evidence, credentials, or local environment files.

Pull requests should be reviewed before merging. Maintainers may request changes, ask for additional tests, or decline changes that do not fit the project scope.
